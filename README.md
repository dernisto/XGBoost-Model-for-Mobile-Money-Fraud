# XGBoost Model for Mobile Money Fraud

A starter machine learning project for detecting potential mobile money fraud using XGBoost.

## Repository Contents

- `README.md` – project overview and setup instructions
- `requirements.txt` – Python dependencies

## Quick Start

1. Create and activate a virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Goal

Build and evaluate an XGBoost-based fraud detection model for mobile money transaction data.
